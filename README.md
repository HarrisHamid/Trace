# Trace

**Understand any Python codebase visually. Ask a question, watch an AI agent trace the answer through the code, and learn the codebase one node at a time.**


## The problem

Developers constantly land in code they did not write: a new job, an open-source repo, or code generated by an AI. The usual way to understand it is to grep across dozens of files and hold the call chain in your head. That is slow, and it is easy to get wrong.

## What Trace does

Trace turns a Python repo into an interactive graph, then lets an AI agent answer questions by walking that graph. Every claim the agent makes is checked against the real call graph before you see it.

## Main features

- **Codebase view:** modules and files as a constellation map of the repo.
- **File view:** the functions and classes inside one file, and how they connect.
- **Click to code:** click any node to open the exact file and line in a code panel.
- **Ask the codebase:** ask "how does login work?" and watch an agent trace the answer node by node. Unverified claims are flagged, and edges the parser could not resolve are shown dashed.
- **Learning mode (toggle):** unexplored nodes go dark. Open one, answer one easy tap-check, and it lights up. A progress bar shows how much of the codebase you understand.

## How it works

```
Python repo
   |
   v
Parser (ast + jedi)  -->  Graph (nodes, edges, flagged gaps)   [no AI]
                              |
          +-------------------+--------------------+
          v                                        v
   Graph tools  <--  Agent (Muse Spark)     Tap-check questions
   (search, source,   picks what to read,   (pre-generated by the
    callers, callees)  max 8 tool calls      model, validated)
                              |
                              v
                  Grounding validator  [no AI]
                  (every node, edge and quote is checked)
                              |
                              v
        FastAPI (streams steps)  -->  Web UI (Cytoscape.js)
```

- **Parser and graph:** deterministic. Python `ast` for structure, `jedi` for name resolution, plus Flask or FastAPI route edges.
- **Agent:** a Meta model in a tool-calling loop. It decides what to read next and returns a structured JSON path.
- **Grounding validator:** plain code that rejects any claim that is not in the graph.
- **Frontend:** a single page, no React.
